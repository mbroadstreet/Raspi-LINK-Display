# fonts

No font file is bundled in this skeleton.

By default, the app searches for common system fonts such as:

- `/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf`
- `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf`
- `/usr/share/fonts/truetype/liberation2/LiberationSans-Bold.ttf`

You may place a locally licensed font at:

```text
assets/fonts/display.ttf
```

Do not redistribute font files unless their license allows it.
